# Brightpan invoice & receipt extraction

Supplier invoices and receipts (digital PDFs, scans, phone photos) turned into validated structured data,
with line-math and duplicate checks, and a review queue for doubtful documents.

Brightpan Kitchen Supply is a fictional store; every vendor, document and number in `samples/` and `truth/` is fictional
and generated by `scripts/make_samples.py`.

**Status:** work in progress. API, worker, validation and duplicate check run end to end; the first full eval
run is in `eval/results.csv`. Mismatches have not yet been reviewed by hand, so no numbers are final.

## Layout

| Path | What it is |
| --- | --- |
| `samples/` | 20 test documents: 10 digital PDFs, 1 two-page PDF, 4 scans, 3 phone photos, 2 receipts |
| `truth/` | Ground truth per document, plus `manifest.csv` (expected route and flags) |
| `eval/run_eval.py` | Uploads every sample to the API, polls until done, scores against `truth/`, writes `eval/results.csv` |
| `eval/scoring.py` | Strict comparison and metrics; every metric is recomputable from `results.csv` |
| `eval/stub_api.py` | Null stub implementing the API contract, used for the baseline run |
| `app/main.py` | FastAPI: upload, status + JSON, original file; starts the worker |
| `app/worker.py` | Claims queued documents from Postgres (`FOR UPDATE SKIP LOCKED`), extracts, validates, stores |
| `app/extract.py` | PDF text layer if present, else page images; photos as images; Claude structured output |
| `app/validate.py` | Required fields, dates, ISO currency, line sum = subtotal, subtotal − discount + tax + shipping = total (±$0.02), duplicate key, routing |
| `app/schema.sql` | Tables `documents`, `extractions`, `review_queue` in schema `invoice_extraction` |

## Run

```bash
uv sync
cp .env.example .env                             # add ANTHROPIC_API_KEY and DATABASE_URL
ALLOW_RESET=1 uv run uvicorn app.main:app --port 8040    # API + worker; tables are created on startup
uv run python eval/run_eval.py                   # all 20 samples
uv run python eval/run_eval.py --from-csv eval/results.csv   # recompute metrics only
uv run pytest -q
```

## API contract

- `POST /documents` (multipart `file`) → `202 {"id", "status"}`
- `GET /documents/{id}` → status (`queued | processing | done | failed`), `record` (extracted JSON), timings, token usage and cost
